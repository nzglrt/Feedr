# Feedr

A minimalist RSS and podcast reader for Android.

Feedr is an open-source RSS and podcast reader designed to provide a clean, distraction-free reading experience. With a minimalist dark interface, customizable themes and useful features, Feedr brings your favorite news sources and podcasts together in one place.


# Features

- **RSS & Podcasts:** Follow your favorite websites, news sources and podcasts.

- **Minimalist Dark Interface:** A clean, dark design focused on readability and simplicity.

- **Topic-based Tabs:** Personalize the app's appearance with different themes.

- **Pinned Articles:** Pin news and articles to read later.

- **Notification Digests:** Receive summarized notifications to stay up to date without constant interruptions.

# Building

The following requirements are needed:

- Android Studio

- Android SDK

- JDK compatible with the project's Gradle configuration


# Instructions

 1. Clone the repository:

     ```bash
    git clone https://github.com/YOUR_USERNAME/Feedr.git

3. Open the project in Android Studio.

4. Wait for Gradle to sync and download the required dependencies.

5. Build the application using Android Studio or run:

   ```bash
   ./gradlew assembleDebug

7. The generated APK will be available at:

   ```bash
   app/build/outputs/apk/debug/app-debug.apk
